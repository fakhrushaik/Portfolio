Project #1 — SeatSavor

A showcase-first 3D restaurant table-booking app: pick your exact table in a pastel isometric room, like booking a seat on a plane.

  • 12-table Three.js floor with free (blue) / occupied (coral) / selected states and click-to-select detail cards
  • Smooth orbit camera with gentle zoom, zoom buttons, zoom-speed setting, and Poster / Top down / Window side / Bar corner presets
  • Light/dark mode and an accessibility mode (larger text, high contrast, reduced motion, visible focus, keyboard navigation)
  • Node.js + Express demo backend: GET /api/tables, GET /api/bookings, POST /api/bookings (in-memory only, no payments, no accounts)
  • Privacy-first demo: no tracking, no advertising cookies — see PRIVACY.md

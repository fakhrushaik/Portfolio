About SeatSavor

Pick your table in 3D, like booking a seat on a plane.

Try our Demo →

What it is

A showcase-first 3D restaurant table-booking demo. A pastel isometric room with 12 clickable tables, detail cards for each table, and camera presets for the poster view, top down, window side, and bar corner. The room was widened in the latest version so tables have real space between them: 6 metres between columns and 5.5 metres between rows, on a 26 by 18 floor.

What you can do in the demo

  • Click a table in 3D, or pick it from the list, to open its detail card: seats, shape, dimensions, zone, and location note, plus a 2D top-down footprint
  • Use camera presets, drag to orbit, scroll or pinch to zoom, and use the + and − buttons and zoom-speed slider for gentle zoom
  • Filter tables by All, Free, or Occupied
  • Switch light and dark mode, and turn on Accessibility mode for larger text, high contrast, reduced motion, visible focus, and keyboard navigation
  • Try the demo booking form in the 3D view

How it is built

JavaScript, Three.js, HTML, and CSS with a Liquid Glass interface. The full project also has a Node.js and Express demo backend for local use: tables and in-memory demo bookings only, with no payments and no accounts. Run it locally with npm install then npm start in the SeatSavor folder, then open http://localhost:3000

What does not work on GitHub Pages, and why

GitHub Pages hosts static sites only. It does not run the Node.js server, so on Pages the 3D picking, camera presets, and table details work from built-in demo data, but demo bookings will say the backend is not reachable. That is expected. To use bookings, run the server locally as above.

Coming soon

Menus, a bookings list, Settings, and Edit Layout are marked Coming soon in the demo. They are not fake buttons.

Privacy

Demo only. Fictional data, no tracking, no advertising cookies, no accounts, no payments. See the full Privacy page.

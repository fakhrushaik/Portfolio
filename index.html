SeatSavor

SeatSavor

3D restaurant table booking · Showcase-first

Pick your exact table in 3D, like booking a seat on a plane. A pastel isometric room with 12 clickable tables, detail cards, camera presets, gentle zoom, light/dark mode, and an accessibility mode.

  • JavaScript
  • Three.js
  • Node.js
  • Express

Live demo About this project

On Pages, 3D picking, camera presets, and table details work. Demo bookings need the local server, run npm start in SeatSavor/, so the booking form will say the backend is not reachable on Pages.

ToothTown

ToothTown

3D dentistry clinic booking · In progress

A SeatSavor-style clinic app built from a hand-drawn floor plan: clinic rooms, staff, patient scheduling, a calendar, available slots, and bookings that stay pending until a doctor approves or rejects them.

  • JavaScript
  • 3D floor plan
  • Booking workflow
  • Database

Live demo About this project

On Pages, ToothTown runs in browser-only mode with fictional demo data saved in your own browser. The full backend and database are in ToothTown/server/ for local use.

About

I'm finishing my IT degree first, graduating in May 2027, and building a portfolio around projects I can actually demo. I like taking a rough idea, a Threads demo, a hand-drawn clinic sketch, a capstone brief, and turning it into something you can click through.

What I care about in a build: it works on a phone, the text is readable in dark mode, keyboard users can get around, and the demo doesn't pretend to be a real service. SeatSavor and ToothTown use fictional demo data only, with no payments and no real reservations.
